# AP Sentinel (v5.2.2)
**Author:** Arunava Dey

## Overview
AP Sentinel is a custom-built automation tool designed to optimize Accounts Payable (AP) workflows within SharePoint and ERP environments (Microsoft Dynamics AX).

### Key Features
* **Smart Scan:** Extracts invoice properties (PO, Inv #, Amount) instantly from SharePoint.
* **Visual Auditor:** Cross-references PDF data with system properties via clipboard matching to eliminate human error.
* **Credit Note Detection:** Automated UI alerts for negative values to ensure correct entry in AX.
* **SOP Integration:** Searchable knowledge base for US-process business rules.

## Technical Details
* **Language:** JavaScript
* **Engine:** Tampermonkey / Greasemonkey
* **Environment:** Citrix / SharePoint
